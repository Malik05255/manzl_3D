# منزل H

محرر مخططات سحابي: ارفع PDF أو صورة، حوّلها إلى نموذج هندسي قابل للتعديل، ثم عدّل يدويًا أو عبر **H Engineer** مع معاينة أثر التغيير قبل اعتماده.

## المنفذ الآن

- PWA عربية Responsive للجوال والتابلت والكمبيوتر والشاشات العريضة.
- قائمة المشاريع الأخيرة على الجهاز مع صلاحية مستقلة لكل مشروع دون حساب إلزامي.
- مسار: ابنِ مشروعك → تعديل مشروع → رفع → تحليل → منطقة التعديل، مع رفع بالنقر أو السحب والإفلات أو لصق صورة من الحافظة.
- R2 للمصادر والنسخ الهندسية، وD1 للمشاريع وسجل النسخ.
- Queue لمعالجة المخططات خارج طلب المستخدم، مع إعادة التحليل من المصدر السحابي بنقرة واحدة عند فشل عابر دون إعادة الرفع.
- Analyzer سحابي: PDF/Image + OCR عربي/إنجليزي + جدران + غرف + معايرة مقياس + درجات ثقة، مع Google Vision OCR اختياري يعمل بالتوازي مع Tesseract ويعود تلقائيًا للمحرك المحلي عند غياب المزود.
- ملفات PDF الرقمية تقرأ طبقة النص الأصلية مباشرة وتدمجها مع OCR لرفع دقة أسماء الغرف والأبعاد.
- H Engineer يدعم أوامر المقاس مثل: `عدل غرفة النوم إلى 5×5`، ويمكنه استخدام الغرفة المحددة مباشرة مع أوامر مثل `اجعلها 5×5`.
- H Engineer يعمل أيضًا على الجدران والفتحات المحددة مباشرة: تحريك الجدار بمسافة، تغيير سماكته، إضافة باب/نافذة، تغيير عرض الفتحة وموقعها ونوعها أو حذفها.
- تغيير مقاسات الغرف المتعامدة غير المستطيلة (مثل L-shape) دون تحويلها قسرًا إلى مستطيل، مع الحفاظ على شكلها وحدود الجيران.
- كل اقتراح يظهر كـPreview ولا يُحفظ قبل الاعتماد، ومعاينة AI متحركة تُظهر تغير الغرف والجدران قبل تثبيت التعديل.
- تحريك جدران يدويًا مع Snap كل 5 سم، تحريك رقمي دقيق بالسنتيمتر، قياس مباشر داخل المخطط، Undo/Redo، حفظ تلقائي للمسودة، وحفظ Revisions واضحة.
- تصحيح الأبواب والنوافذ يدويًا: إضافة، حذف، تغيير النوع، ضبط العرض، وتحريك الفتحة على الجدار.
- تصدير المخطط الحالي بصيغ SVG/PNG/JSON دون الاعتماد على خدمة مدفوعة.
- استعادة نسخة مشروع JSON والتحقق من بنيتها قبل إدخالها إلى مشروع سحابي جديد.
- تحديث PWA دون حذف المشاريع السحابية.
- CI للواجهة والـAPI ومحرك التحليل.

- ملفات PDF متعددة الصفحات تحفظ عدد الصفحات، ويمكن إعادة تحليل أي صفحة من داخل المحرر دون إعادة رفع الملف، مع إبقاء الصفحة السابقة في سجل النسخ.

- OCR يقرأ أيضًا الأبعاد الرأسية ويحوّل الوحدات الصريحة cm/mm/سم/مم إلى أمتار عند معايرة المقياس.

- مراجعة قراءة موجهة للعناصر منخفضة الثقة: الغرف والجدران والأبواب والنوافذ تظهر للمستخدم للتأكيد أو التصحيح بدل اعتبارها صحيحة تلقائيًا.

- وضع Pan آمن للجوال واللمس يمنع تحريك الجدران بالخطأ أثناء تصفح المخطط، مع سحب مساحة العمل باللمس أو الماوس.

- Queue التحليل مرتبط بالمصدر والـRevision مع فحص قبل وبعد التحليل، لمنع نتيجة قديمة من الكتابة فوق رفع أو تعديل أحدث.

- كل عنصر هندسي يحتفظ بدرجة الثقة الأصلية و`provenance` لمصدر الاستخراج، بينما تحفظ المراجعة البشرية في `reviewed` بشكل مستقل بدل تزوير الثقة إلى 100٪.

- H Engineer يرفض تعديل غرفة أو جدار أو فتحة منخفضة الثقة قبل تأكيدها بصريًا، والعناصر غير المؤكدة تظهر باللون البرتقالي داخل منطقة التعديل.

- callbacks الخاصة بالتقدم والمعاينة مرتبطة ذريًا بـ`sourceKey + revision`، ومعاينات R2 القديمة تُنظف تلقائيًا ولا تستطيع نتيجة قديمة تغيير حالة مشروع أحدث.

- محرك التحقق يكتشف الآن تقاطع حدود الغرفة مع نفسها والتداخل بين الغرف غير المستطيلة أيضًا، وليس المستطيلات فقط.

- الحفظ التلقائي وH Engineer واستعادة النسخ لا تتسابق مع تحليل مصدر جارٍ؛ عمليات التحرير تنتظر حتى تصبح النسخة السحابية جاهزة.

- أضيفت علاقات topology صريحة بين كل غرفة والجدران التي تحدها عبر `boundaryWallIds`؛ يعاد ربطها بعد تعديلات H Engineer بدل الاعتماد على مضلع منفصل فقط.

- الجدران المحتمل أنها خارجية تُصنف تلقائيًا بعد فهم topology وتُحمى من السحب والتعديل الآلي حتى يفك المستخدم الحماية صراحة.

- يمكن للمستخدم تصنيف الجدار يدويًا كداخلي أو خارجي أو إنشائي أو غير محدد؛ الجدار الإنشائي يبقى محميًا حتى تغيير تصنيفه.

- الخادم يفرض حماية الجدران والفتحات المرتبطة بها عند الحفظ، وليس الاعتماد على تعطيل الأزرار في الواجهة فقط.

- التعديلات اليدوية وH Engineer تحدث `provenance` للعناصر المتغيرة إلى حالة مختلطة مع إبقاء ثقة الاستخراج الأصلية مستقلة.

- بيانات الطوابق نفسها — الاسم والمنسوب والارتفاع — تدخل سجل Revisions ويمكن استعادتها مع النسخة بدل بقائها إعدادات خارج التاريخ.

- مصدر قراءة النص محفوظ في `provenance` بشكل منفصل بين OCR المحلي و`cloud-ocr` وطبقة نص PDF الأصلية، وتظهر هذه المعلومة أثناء مراجعة العناصر منخفضة الثقة.

## البنية

```text
apps/web             React + TypeScript + Vite PWA
apps/api             Cloudflare Worker + D1 + R2 + Queue
packages/contracts   Canonical FloorPlan contracts
services/analyzer    FastAPI + OpenCV + Tesseract + PyMuPDF + Cloud OCR اختياري
```

راجع `docs/ARCHITECTURE.md`.

## تشغيل سريع

```bash
npm install
npm run build
npm run dev:web
```

للـAnalyzer:

```bash
cd services/analyzer
pip install -r requirements-dev.txt
PYTHONPATH=. pytest -q
docker build -t manzil-h-analyzer .
```

لرفع جودة OCR بدون كشف المفتاح للواجهة، انسخ `services/analyzer/.env.example` إلى متغيرات بيئة خدمة الـAnalyzer فقط. عند تفعيل `CLOUD_OCR_PROVIDER=google-vision` يوضع `GOOGLE_VISION_API_KEY` في سرّ الخادم/الحاوية، ولا يضاف إلى أي متغير `VITE_*` أو كود المتصفح.

أنشئ D1 وR2 وQueue، ثم انسخ `apps/api/wrangler.jsonc.example` إلى `wrangler.jsonc`. ضع نفس `INTERNAL_TOKEN` في Worker وAnalyzer، واضبط `ALLOWED_ORIGIN` على رابط واجهة الويب. إذا لم تضبطه فالـAPI يسمح افتراضيًا بطلبات نفس الأصل فقط.

> التصميم Free-first، لكن حصص الخدمات المجانية قابلة للتغيير. نموذج المشروع نفسه غير مربوط بمزود AI واحد.
